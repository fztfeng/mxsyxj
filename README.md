# 今日水印相机

> 一款支持实时定位修改和时间修改的水印相机应用

## 简介

今日水印相机是一款功能强大的水印拍照应用，支持自定义时间、位置信息，提供多种水印模板，让你的每一张照片都带有专业的水印信息。无论是工作记录、考勤打卡还是生活记录，今日水印相机都能满足你的需求。

## 功能特性

### 核心功能
- **实时相机预览** - 支持前后摄像头切换，实时显示水印效果
- **水印拍照** - 拍摄时自动将水印合成到照片中
- **多模板支持** - 经典、简约、现代、专业四种水印模板
- **自定义时间** - 可自由修改照片上的日期和时间
- **自定义定位** - 支持手动输入位置或自动获取GPS定位
- **自定义文字** - 添加个性化备注文字到水印中
- **品牌防伪水印** - 每张照片右下角自动添加"今日水印"品牌标识和蓝色"真实可验"徽章
- **13位防伪码** - 每次拍照自动生成唯一13位防伪码（大写字母+数字），烧录到照片中
- **照片验真** - 输入防伪码即可验证照片真伪，查看完整拍摄信息
- **自动定位** - 启动时自动获取GPS定位，支持低精度→高精度→IP定位→默认城市四级容错

### 相机功能
- 前后摄像头切换
- 闪光灯控制（关闭/开启/自动）
- 4K超高清拍照（最高4096x2160，自动降级到设备最高支持分辨率）
- AI画质增强（锐化卷积滤波器）
- 前置摄像头镜像翻转处理

### 水印模板
| 模板 | 时间 | 日期 | 位置 | 备注 | 特色 |
|------|------|------|------|------|------|
| 经典 | 大字体 | 支持 | 支持 | 支持 | 简洁明了，适合日常 |
| 简约 | 中字体 | 支持 | 不显示 | 支持 | 极简风格，干净利落 |
| 现代 | 大字体 | 支持 | 支持 | 支持 | 带今日徽章，时尚现代 |
| 专业 | 完整日期时间 | - | 支持 | 支持 | 左侧竖线设计，商务风格 |

### 水印样式自定义
- 水印位置（左下/右下/底部居中/左上/右上）
- 字体大小（小/中/大）
- 水印透明度（30%-100%）

### 防伪与验真
- **品牌水印** - 照片右下角显示"今日水印"品牌名称和"相机 [真实可验]"蓝色徽章副标题
- **防伪验证码** - 每张照片生成唯一13位防伪码（大写字母+数字），烧录到照片右下角
- **照片验真** - 通过顶部按钮或侧边菜单进入验真页面，输入防伪码验证
- **验真结果** - 显示防伪码、保存时间、水印时间、拍摄位置等完整信息
- **防伪设置** - 可在设置面板中独立开关品牌水印和防伪码功能

### 天气信息系统
- **自动获取天气** - 基于Open-Meteo API（免费无需Key），根据GPS坐标自动获取实时天气
- **三级容错机制** - Open-Meteo → wttr.in(坐标) → wttr.in(IP定位)，确保天气获取成功率
- **自动/手动切换** - 设置面板支持Tab切换自动获取或手动输入天气信息
- **天气信息展示** - 自动模式显示天气图标、天气描述、温度、湿度、风速、体感温度、数据来源
- **一键刷新** - 可手动点击刷新按钮获取最新天气数据
- **10分钟缓存** - 天气数据缓存10分钟，定时自动刷新，减少API请求
- **定位联动** - 获取GPS定位成功后自动获取对应位置的天气信息
- **WMO代码映射** - 完整的WMO天气代码到中文描述+emoji图标映射（30+天气类型）
- **天气元数据** - 拍照时保存完整天气详情（温度、湿度、风速、体感温度等）到照片元数据

### 其他功能
- 内置相册管理（最近20张照片）
- 照片分享（支持系统分享）
- 照片下载保存
- PWA支持，可添加到主屏幕
- 设置自动保存

### 用户系统
- **登录/注册** - 支持手机号/邮箱注册账号，登录后同步用户信息
- **VIP会员** - 三档套餐（月度/年度/终身），解锁全部模板、无限存储、高清视频、团队协作、云端同步
- **团队管理** - 创建团队生成邀请码，或输入邀请码加入团队，查看团队统计信息

### 拍摄模式
- **照片模式** - 默认拍照模式，实时水印预览
- **照片编辑** - 从相册选择照片重新编辑水印
- **视频模式** - 视频录制模式
- **边拍边拼** - 2/3/4张照片拼图合成，支持实时拍照填充和一键导出
- **拼图汇报** - 输入标题和内容，添加照片，生成专业汇报图

## 快速开始

### 环境要求
- 现代浏览器（Chrome 60+, Firefox 55+, Safari 11+, Edge 79+）
- 需要HTTPS环境（或localhost）才能访问摄像头
- 设备需要有摄像头

### 本地运行

1. 使用Python启动本地服务器：
```bash
cd moxi-watermark-camera
python3 -m http.server 8080
```

2. 使用Node.js启动：
```bash
npx http-server -p 8080
```

3. 在浏览器中访问 `http://localhost:8080`

### 部署到服务器

将整个 `moxi-watermark-camera` 目录上传到支持HTTPS的Web服务器即可。

> **注意**：摄像头API需要HTTPS环境（localhost除外），请确保部署环境支持HTTPS。

## 使用说明

### 基本使用
1. 打开应用，允许摄像头权限
2. 取景框中实时显示水印效果
3. 点击底部圆形按钮拍照
4. 在预览页面确认后保存或重拍

### 修改时间
1. 点击右上角设置图标
2. 打开"时间设置"开关
3. 选择自定义日期和时间
4. 或点击"同步当前时间"快速恢复

### 修改位置
1. 点击右上角设置图标
2. 打开"位置设置"开关
3. 点击"获取当前定位"自动获取GPS位置
4. 或手动输入省份、城市、详细地址

### 切换模板
1. 点击右上角设置图标
2. 在"水印模板"区域选择喜欢的模板
3. 水印预览实时更新

### 查看相册
1. 点击左下角相册图标
2. 查看已拍摄的照片
3. 点击照片查看大图
4. 点击删除图标移除照片

### 照片验真
1. 点击顶部"照片验真"按钮，或打开侧边菜单选择"照片验真"
2. 在输入框中输入照片上的13位防伪码
3. 点击"立即验证"按钮
4. 验证通过后显示照片的完整信息（防伪码、保存时间、水印时间、拍摄位置）
5. 同时显示对应照片缩略图，直观确认

### 防伪设置
1. 点击水印编辑按钮打开设置面板
2. 找到"防伪与品牌"区域
3. 可独立开关"品牌水印"和"防伪验证码"
4. 面板中实时显示当前防伪码预览
